改善点

  1. 01
    コード・設定に直接書かれたキーを環境変数などに移す

    安全 ／ S1

    たとえばこんなプロンプト
    コードや設定に直接書かれた認証情報を、値を表示せずに探してください。環境変数や秘密情報の管理機能に移す変更案と、キーの再発行が必要な箇所を示してください。
  2. 02
    .env 系と鍵・認証情報系の両方を、読ませない設定にする

    安全 ／ S2

    たとえばこんなプロンプト
    AIが読む範囲の設定を確認し、.env 系のファイルと秘密鍵・認証情報の両方を読み取り対象から外す案を出してください。実際の秘密ファイルは開かず、見本で確認してください。
  3. 03
    消す・強制上書き・外へ出す操作を、すべて承認制か禁止にする

    安全 ／ S3

    たとえばこんなプロンプト
    削除・強制上書き・外部送信に関する許可設定を確認してください。操作の種類ごとに、実行前の承認を必須にするか禁止する変更案を示してください。

点検の範囲

  • claude.ai や ChatGPT などの、チャット画面だけでの利用は数えていない（PCに残る記録だけを見ている）。
  • Codex の会話の記録は、標準機能で読める形になっていないため、使用実績が要る項目は「測定できず」にしている。
  • この点検で検出した道具: Claude Code、Codex。
  • キーの走査の限界: よくある形のキー（sk-・AIza等）と、設定ファイルの中の名前でわかるもの（token・secret等）だけを探している。1MBを超えるファイルと、Gitの対象外のファイル（.env等）は見ていない。
  • 小文字だけの値や、小文字・数字・ハイフンだけの値は、名前や見本とみなして数えない。
  • 秘密ファイルを読ませない設定（S2）と、取り返しのつかない操作の承認（S3）は、設定の行とフックの中身に、系統ごとの語が書かれているかだけを見ている。フックを実行して、本当に止まるかは試していない。
  • 直近30日の日別グラフと「使われている／眠っているもの」「任せて動いた量」は、Claude Code の会話の記録だけから作っている。
  • 今月の使用時間の合計は、Claude Code と Codex の値を単純に足したもの。同時に両方を使っていた時間があれば、その分は重複して数えている。
  • Codex のトークンは、会話の記録が圧縮されていて読めない分は足していない（推測で埋めていない）。
